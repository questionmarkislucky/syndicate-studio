# Syndicate

Static Roblox game studio website, featuring Chop A Forest.

## GitHub Pages

Publish from the `main` branch, root folder. The `.nojekyll` file makes GitHub serve the files directly.

Edit `index.html`, `style.css`, and `app.js` to update the website. Artwork is in `assets/`.

Game statistics are a dated snapshot, checked on 13 October 2026; source links are shown on the game card.
